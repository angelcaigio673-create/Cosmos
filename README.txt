Cosmos: граф для OSINT-расследований (версии для ПК и телефона)

ФАЙЛЫ
  index.html   автоматически открывает нужную версию (телефон или ПК)
  pc.html      версия для компьютера (полная панель, горячие клавиши)
  m.html       версия для телефона (нижняя панель действий под большой палец)
  bg/          веб-фоны высокого качества (WebP, загружайте папку целиком)
  icons/       иконки приложения и PWA
  assets/      официальный логотип Cosmos (logo.jpg)
  manifest.webmanifest, sw.js   установка как веб-приложение и работа оффлайн

НОВЫЕ ВОЗМОЖНОСТИ
  Виды связей  В меню "Вид" можно переключать типы трейлов:
               - Стандарт: ровные кривые Безье без лишнего свечения в покое
               - Неон: светящиеся неоновые трубки с цветным ореолом (Halo) и нитью накала
               - Поток: бегущие световые импульсы по связям
               - Ступени: ортогональные прямые линии под 90 градусов

  Цвета связей Выбор палитры связей в меню "Вид" под стили фонов:
               - Авто: цвет берется от категории исходного объекта
               - Лазурь: неоновый лазурный (стиль Космос / Horizon)
               - Фиолет: глубокий фиолетовый (стиль Небула / Mesh violet)
               - Изумруд: радарный матричный изумруд (стиль Топо)
               - Графит: стальной сдержанный титан (стиль Мегаполис)
               - Лед: чистый арктический ледяной свет (стиль Зимний лес)
               - Око: глубокий тревожный малиновый (стиль Наблюдение / Eyes)
               (Панель кнопок прокручивается колесиком мыши на ПК и свайпом на телефоне).

  Толщина      Ползунок "Толщина линий связей" (от 1px до 5px):
               настраивайте степень жирности линий в реальном времени.

  Анимация     В настройках добавлен переключатель "Анимация связей":
               позволяет включать или выключать движение импульсов и частиц
               (при выключении схема становится полностью статичной).

  Подсветка    При клике на любой прямоугольник:
               - Связанные с ним трейлы мгновенно отсвечивают ярким
                 неоновым лучом и направленным импульсом в цвет стиля.
               - Связанные карточки подсвечиваются цветным ореолом.
               - Несвязанные объекты плавно затеняются, фокусируя внимание.
               При наведении курсора трейлы также мягко подсвечиваются.
               Клик в пустое место (или Esc) возвращает стандартный вид.

  Снимок (P)   Формирует 2K фото всей схемы без скачивания файла:
               кнопка "Скопировать картинку" копирует изображение прямо в буфер
               (вставляйте Ctrl+V сразу в Telegram, Discord, Word),
               кнопка "В новой вкладке" открывает картинку во весь экран.

  Чистый (F)   Чистый режим экрана: скрывает все кнопки и панели для
               презентации схемы (выход - Esc или кнопка в углу).

  Вид/Настройки Сетка белых точек настраивается: ползунок яркости в меню "Вид",
               выбор из 12 тем оформления.

ЗАПУСК НА КОМПЬЮТЕРЕ
  Откройте index.html или pc.html в любом браузере.

ВЫКЛАДКА НА САЙТ (бесплатно со своим доменом)
  Cloudflare Pages (рекомендуется):
    1. Зайдите на pages.cloudflare.com.
    2. Workers & Pages > Create > Pages > Upload assets.
    3. Перетащите папку Cosmos целиком (или zip).
    4. Адрес имя.pages.dev выдается сразу, свой домен подключается
       во вкладке Custom domains с бесплатным SSL.
  GitHub Pages:
    Загрузите содержимое папки в репозиторий, Settings > Pages > Deploy from a branch.

УПРАВЛЕНИЕ
  Клик по карточке - подсветка и отсвечивание всех связанных связей
  P - сделать снимок визуализации (HD)
  F или H - чистый экран (Zen режим)
  N - создать узел, L - связать, Пробел - вписать схему по центру
  Ctrl+K - поиск по уликам, Ctrl+Z / Ctrl+Y - отмена и повтор
  Delete - удалить выбранный узел, Esc - снять выбор / закрыть окно
  Двойной клик по пустому месту - создать новый узел

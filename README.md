# Cosmos // OSINT Tactical Intelligence Platform

Профессиональная платформа визуализации графов связей, разведывательного анализа и генерации досье в фирменной стилистике Cosmos Dark Matrix.

Полное соответствие эталонному дизайну: компактные карточки объектов с цветным левым акцентным маркером, иерархическая раскладка улик, сглаженные кубические кривые Безье, спектральный виджет и галерея обоев. Официальный логотип: `assets/logo.jpg`.

---

## Быстрый запуск на компьютере
Просто откройте `index.html` в любом браузере (Chrome, Edge, Firefox, Safari). Всё работает автономно без интернета и без необходимости установки каких-либо модулей или сборщиков.

## Ключевой функционал и новые возможности

### 1. Формирование чистого фото визуализации (Снимок)
- Кнопка **«Снимок»** на верхней панели (или клавиша `P` на клавиатуре): формирует изображение всей вашей схемы в разрешении 2K Ultra HD без элементов интерфейса (шапок, кнопок и меню) — в точности как на эталонном снимке.
- **Копирование в буфер в 1 клик** (`Скопировать картинку`): изображение помещается напрямую в буфер обмена системы через Clipboard API. Вы можете сразу вставить его (Ctrl+V) в Telegram, Discord, WhatsApp, Word или презентацию без необходимости сохранять файл на диск.
- **Просмотр в новой вкладке**: открытие изображения во весь экран.
- **Сохранение файла**: сохранение снимка в формате PNG.

### 2. Чистый режим презентации (Zen Mode)
- Кнопка **«Чистый»** на верхней панели (или клавиши `F` / `H`): одним кликом скрывает весь интерфейс, панели инструментов, кнопки и виджеты, оставляя только ваш интерактивный граф и космический фон для демонстраций и захвата экрана.
- Выход из чистого режима — клавиша `Esc` или плавающий бейдж в правом верхнем углу.

### 3. Центр настроек (Settings Modal)
- Кнопка **«Настройки»** объединяет все визуальные и системные параметры в аккуратном диалоговом окне:
  - **Матрица белых точек**: тумблер включения/выключения фоновой точечной сетки и плавный регулятор её яркости (прозрачности).
  - **Фоновые темы**: интерактивная галерея обоев (Космос, Черная дыра, 3D Сетка, Наблюдение, Зимний лес, Туманный город, Облака, Полутон, Без фона, а также загрузка своего фото).
  - **Затемнение и размытие**: тонкая настройка читаемости текста карточек поверх любого фона.
  - **Космические частицы**: выбор динамики (Звездное поле, Медленная пыль, Выключено).
  - **Трассировка связей**: включение/выключение анимированного потока световых импульсов по линиям, а также выбор толщины линий (Тонкая 1.2px, Стандарт 1.8px, Плотная 2.5px).
  - **Виджет спектра связей**: переключатель отображения нижней спектральной панели.
  - **Режим интерфейса**: Авто, Принудительный ПК, Принудительный Мобильный.
  - **Язык**: Русский / English.
  - **Сброс**: возврат графа к эталонному кейсу расследования.

### 4. Оптимизация и производительность
- Отложенное автосохранение состояния (Debounce 200мс), исключающее задержки при перетаскивании карточек.
- Анимационный цикл фоновых частиц автоматически приостанавливается, когда вкладка браузера неактивна или частицы отключены в настройках.
- Точечный пересчет координат связей только для перемещаемого узла.

## Версии для ПК и Телефона
Платформа адаптируется под любые экраны:

1. **Версия для ПК (Desktop Workstation):**
   - Полная панель инструментов сверху: поиск по горячей клавише Ctrl+K, быстрое добавление узла (N), режим связывания (L), авто-раскладка, масштабирование (Space), отмена (Ctrl+Z) и возврат (Ctrl+Y).
   - Всплывающие панели управления экспортом, кейсами и досье.
   - Плавающее контекстное меню действий при наведении на любой узел сети.
   - Навигация мышью: перетаскивание холста, зум колесом к курсору.

2. **Версия для Телефона (Mobile Touch Edition):**
   - Сенсорный интерфейс с адаптацией под экраны смартфонов и Safe Area (челка, панель жестов).
   - Нижняя панель действий под большой палец: Объекты, Связи, Раскладка, Снимок, Вписать, Меню.
   - Выдвижная шторка (Bottom Sheet) для просмотра и редактирования карточек по тапу.
   - Сенсорное панорамирование одним пальцем и масштабирование двумя пальцами (Pinch-to-zoom).
   - Режим устройства можно принудительно зафиксировать в Настройках.

## Бесплатное размещение в сети со своим доменом

### Вариант 1: Cloudflare Pages (Самый быстрый и надежный)
1. Зарегистрируйтесь на [pages.cloudflare.com](https://pages.cloudflare.com/) (бесплатно, навсегда).
2. Нажмите **Workers & Pages** -> **Create application** -> **Pages** -> **Upload assets**.
3. Укажите имя проекта (например, `cosmos-recon`) и просто перетащите папку `Cosmos` в окно браузера.
4. Нажмите **Deploy site**.
5. Сайт сразу станет доступен по адресу `https://cosmos-recon.pages.dev`.
6. Чтобы привязать свой домен: в настройках проекта перейдите в **Custom domains** -> **Set up a custom domain**, введите ваш домен. Cloudflare автоматически выпустит бесплатный SSL-сертификат и настроит защиту от DDoS.

### Вариант 2: GitHub Pages
1. Создайте публичный или приватный репозиторий на [github.com](https://github.com/).
2. Загрузите файлы проекта в ветку `main`.
3. Перейдите в **Settings** -> **Pages** -> в секции **Build and deployment** выберите Source: **Deploy from a branch**, ветку **main** / **root**, сохраните.
4. Сайт будет опубликован по адресу `https://ваш-логин.github.io/имя-репозитория/`.
5. Свой домен привязывается там же в поле **Custom domain**.

### Вариант 3: Vercel
1. Зайдите на [vercel.com](https://vercel.com/).
2. Импортируйте проект или установите Vercel CLI (`npm i -g vercel`) и выполните команду `vercel` в папке проекта.
3. В проект уже включен готовый файл конфигурации `vercel.json`.

## Горячие клавиши
- `P`: Сформировать снимок визуализации (HD Photo)
- `F` или `H`: Чистый экран (Zen режим презентации)
- `Esc`: Выход из чистого режима / закрытие любого модального окна
- `Ctrl + K`: Фокус в строку поиска по объектам
- `N`: Создать новый узел расследования
- `L`: Режим быстрого связывания узлов кликом
- `Space`: Вписать всю схему по центру экрана
- `Delete` или `Backspace`: Удалить выбранный узел
- `Ctrl + Z`: Отменить последнее действие
- `Ctrl + Y`: Повторить отмененное действие
- Двойной клик по пустому полю холста: Создать новый узел в точке клика
